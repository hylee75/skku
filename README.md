# 성균 성장록 (SKKU Growth Log)

대학생을 위한 3분 키워드 회고 · 인의예지 역량 진단 · 성장 로드맵 · 맞춤 공지 앱.
Google Apps Script + HTML/CSS/JS, 데이터는 구글 시트 `My_Records` 한 장에 누적됩니다.

## 파일 구성

| 파일 | 역할 |
|---|---|
| `appsscript.json` | 시간대(Asia/Seoul), OAuth 권한, 웹앱 설정 |
| `Code.gs` | 시트 읽기/쓰기, 태그 카탈로그, 진로 설정, Gemini 코칭, 공지·선배 샘플 DB |
| `Index.html` | 화면 뼈대 (헤더, 4개 탭, 하단 탭 바, 시트/모달) |
| `Style.html` | 반응형 CSS (성균 녹색 + 금색, 모바일 우선, 다크모드 대응) |
| `Script.html` | 클라이언트 로직 (레이더 차트, 드릴다운, 기록 폼, 로드맵 캔버스, 공지 필터) |

## 설치

1. [script.google.com](https://script.google.com) 에서 새 프로젝트를 만들고 위 5개 파일을 같은 이름으로 추가합니다.
   (`.gs` 는 `Code.gs`, 나머지는 HTML 파일, `appsscript.json` 은 설정 > "appsscript.json 매니페스트 표시" 체크 후 붙여넣기)
   또는 `clasp` 로 `clasp push`.
2. **프로젝트 설정 > 스크립트 속성**에 추가:
   - `GEMINI_API_KEY` = (본인 Gemini API 키)
   - `GEMINI_MODEL` = (선택) 사용할 모델 ID. 기본값은 `gemini-3-flash-preview` 이며, Google AI Studio 의 모델 목록에서 정확한 ID 를 확인하세요.
3. 배포 > 새 배포 > 웹 앱 > 실행 계정 "나", 액세스 권한은 필요에 맞게 선택.
   첫 실행 때 스프레드시트/외부 요청 권한을 승인합니다.
4. 시트 `My_Records` 가 없거나 비어 있으면 첫 저장 시 헤더가 자동 생성됩니다.

## 보안 주의

- **API 키를 코드나 GitHub 에 절대 넣지 마세요.** 이 프로젝트는 스크립트 속성에서만 키를 읽습니다.
- 대화창 등에 한 번이라도 노출된 키는 폐기하고 새로 발급하는 것이 안전합니다.
- 웹앱을 "모든 사용자"로 공개하면 시트 데이터가 같은 계정(배포자) 권한으로 읽히고 쓰입니다. 학교 도메인 사용자로 제한하거나, 사용자별 시트 분리를 고려하세요.

## 동작 요약

- **점수**: 선택한 태그 1개당 매핑된 가치(인·의·예·지)에 +10pt. 레벨은 0/40/80/120/150pt 기준.
- **목표치**: 진로별 핵심 가치 120pt, 나머지 80pt.
- **로드맵/프로필**은 시트 구조(22개 컬럼)를 건드리지 않도록 사용자 속성(JSON)에 저장합니다.
- **공지·선배 스토리**는 `Code.gs` 의 `noticesDb_()`, `seniorsDb_()` 샘플 데이터입니다. 실제 데이터로 교체하세요.
- 모바일에서는 드래그 대신 "활동 탭 → 학기 탭"으로 로드맵에 배치합니다.
